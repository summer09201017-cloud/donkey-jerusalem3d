# 騎驢進耶路撒冷 3D(donkey-jerusalem3d)

> HFPC 聖經遊戲系列 · 棕枝主日(馬太福音 21:1-11)。**fork 自 equestrian3d 騎乘引擎**(2026-07-16)。
> ★你扮演的是那匹**小驢駒**,馱著主耶穌走進耶路撒冷——**不操控耶穌**,主只是安坐在你背上。

「看哪，你的王來到你這裡！他是公義的，並且施行拯救，謙謙和和地騎著驢，就是騎著驢的駒子。」(亞9:9,和合本,已 cuv 查驗)

## 玩法

- **進城之路**:馱著主耶穌走完全程=進耶路撒冷。沿途一站站歡呼的人群湧上來——
  在**綠區**按「穩步」穩住驢駒就穩穩通過(群眾揮棕枝歡呼);錯過時機=驢駒受驚 +4 罰分(小踉蹌)。
  超時每 4 秒 +1 罰分;**零罰分=又忠心又良善,「溫柔的王進城了!」**(天降彩花+曉臻唸亞9:9)。
- **練習小路**:無限圈數自由練節奏與穩步。

驢駒會沿土路自己走——按住「快步」(W/↑)拿捏節奏,人群靠近時在綠區按「穩步」(空白鍵/點畫面)。
判定=畫面:按下當下定結果,棕枝在驢駒通過後才歡快搖動。不會摔、不會淘汰:來不及按=驢駒自己撐一下,永遠走得完。

- **驢駒毛色三檔**:灰褐/深灰/淺棕(首頁選單即時換色)。
- 五難度(幼兒不限時+強輔助 → 職業 11 站窄綠區)。
- 場景:猶大地土路、橄欖樹、棕櫚樹、地上鋪的彩衣,遠處耶路撒冷城牆與城門。

## 開發

```bash
npm install
npm run dev                      # 本機試玩(dev 不註冊 SW)
npm run build                    # 產物在 dist/
node scripts/gen-voice.mjs       # 烤人聲(雲哲 10 句+曉臻 2 節;產物進 git,離線可玩)
node scripts/verify-donkey.mjs <url> <outDir>  # Playwright 端到端(完美驢駒/全受驚/換色)
```

引擎重點(承 equestrian3d):CatmullRom 閉環賽道(`posAt/tangentAt` 里程域)、skijump 同款綠區判定式
`quality = 1 - err/(window*2.2)`、四足 makeDonkey(矩形身體+雙節腿+有臉+大長耳)、
耶穌=系列 makePerson 白袍坐姿(引擎控 NPC)。人聲鐵律:預烤 mp3,缺檔只出字幕。
